# Monster Shop Idle (monster-shop-idle)

An idle clicker about running dodgy shops, named Monster Shop Idle (Rob's choice for the app as a whole; "Grizzle's Haunted Mall" is now just the first setting). Settings: a goblin in a haunted mall, an ex-smuggler on a space station, a pirate ship, a cyberpunk night market and a robot planet. Hobby project by Rob Stibal, inspired by the structure of the discontinued mobile game *It's Always Sunny: The Gang Goes Mobile* (schemes, episode-style prestige, character cards) but with an original setting and cast. Do not use that show's names or characters.

## Layout

- `index.html`: the whole game (HTML, CSS, JS in one file, no build step, no dependencies)
- `tools/sim.mjs`: balance simulator, run with `node tools/sim.mjs`. It reads the numbers straight out of `index.html` (`SCHEMES`, `MILESTONES`, `SKINS` (for the first skin's shop names), `GOALS`, `GOALS_NEEDED`, `CARDS`, `CHESTS`, `LEVEL_AT`, `PERM_PER_EPISODE`, `EPISODE_COST_GROWTH`, `OFFLINE_CAP_S`, `EGGS_PER_GOAL`) with regexes, so keep those blocks in their current shape (`const X = [` ... `\n  ];`, and single-line number constants). It prints episode 1 in detail, then median times for several episodes in a row for engaged, casual and idle profiles (`node tools/sim.mjs [episodes] [runs]`; env vars `GROWTH`, `OFFRATE`, `OFFCAP` try what-ifs).
- `README.md`: player-facing rules, card and chest tables, tuning pointers
- `manifest.webmanifest`, `sw.js`, `icons/`: make it installable as a home-screen app. The service worker is network first (cache only as the offline fallback), so pushes show up without cache busting; bump `CACHE` in `sw.js` if its file list changes. Icons are drawn by `tools/make_icons.py` (Pillow). The in-app browser pane can't register service workers, so test offline behavior in real Chrome. `theme-color` follows the skin's `bg` in `applySkin`.

## How the game works (current state)

- Skins: everything players read or see lives in `SKINS` (owner, words for customers, currency names, chest names, the cast on each card, shop hues, episodes with shops/story, and a `theme` of CSS variables plus a Google Fonts URL). Mechanics (`SCHEMES`, `CARDS`, `CHESTS`, goals) are shared, so saves work in any skin. Five skins: `mall` (Grizzle's Haunted Mall, Dripping ectoplasm palette: slime green and lilac on green-black with Rubik Wet Paint, which Rob picked on 2026-09-29 from 12 options over the earlier Moonlit graveyard with Alegreya), `starport` (Juno Vance on Starport Nine, navy/amber/teal with Russo One), and three added 2026-09-29 at Rob's request: `ship` (Captain Nell on The Salty Gull, Jolly Roger black/bone/red with New Rocker, Rob's pick on 2026-09-30 over the first night sea/gold look), `neon` (Kix in the Neon Night Market, black-violet/magenta/cyan with VT323 pixel headings, Rob's pick on 2026-09-30 over Audiowide) and `robot` (Rivet on Planet Cog, gunmetal/lime/orange with Tilt Warp). Avoid uppercase-only display fonts (Bungee, Rubik Mono One): Rob doesn't want all-caps labels. Picked in the side panel (pref key `...-skin`) or forced with `?skin=`. A theme can set `display-size` (default 1) to scale headings when its display font runs small (neon's VT323 uses 1.4); `applySkin` resets it for skins without one. The CSS `:root` defaults, the `skinFonts` link, the `theme-color` meta, the manifest colors and the icon colors in `tools/make_icons.py` all mirror the mall theme, so change them together; every color is a variable, so add new colors as theme variables, not hex in rules.
- Six shop slots, unlocked in order. Numbers per slot live in `SCHEMES` (cost, growth, payout, run time, automate cost). Names, icons, nouns and story text per episode live in each skin's `episodes`. Costs grow geometrically, milestones at 10/25/50/100/150 customers double a shop's income and give 1 beer.
- Prestige = episode finale. Needs `GOALS_NEEDED` (5) of the 9 goals plus one customer of the sixth shop. Resets cash and shops; keeps beer, eggs, crystals and cards; gives 3 eggs and multiplies the permanent income bonus `S.perm` by 1 + `finaleGain()` (x1.5, or x2 with the finale card maxed). It multiplied from 2026-09-29; before that it added +50%, and old saves just keep whatever `perm` they had.
- Episodes: five per skin (mall: Haunted Mall, Swamp Market, Crypt Quarter, Midnight Carnival, Sunken Casino; starport: Docking Ring, Hydroponics Deck, Reactor Row, Zero-G Stadium, Pirate Moon), then they repeat ("Haunted Mall 2"). Each finale's last line hands off to the next district, and episode 5's leads back to episode 1, so adding an episode means rewriting the previous finale's ending. All episodes share the same `SCHEMES`, but customer costs, automation costs and goals marked `scaled: true` (the cash goal, `{$}` in its text) multiply by `costMult()` = `EPISODE_COST_GROWTH ^ episode` (2.5, so x2.5, x6.25, x15.6, ...).
- Cards level 1 to 5 by duplicates and survive resets. Each is one multiplier, strength per level in its `per` field, applied through `cardBonus(id)` in the Math section (the simulator mirrors those formulas). Card ids are the effect: `money` all income, `speed` run speed, `discount` cost discount, `finale` finale bonus, `milestone` milestone multiplier (2 + bonus), `beer` milestone currency per milestone (1 + bonus; beer can be fractional and shows rounded down); the skin says who is on each (mall: Grizzle, Mort, Countess Vex, Bramble, Old Bog Witch, Fang). Six cards on purpose, so the card grid fills rows of 2 and 3 evenly; chests go three across or stack, never 2 + 1. Saves from before skins used the mall cast as ids and are migrated in `load()`. Rob prefers multiplier cards (speed, money, finale bonus) over rule-changing perks like free automation or offline caps. Saves from before this (no `cardsV2`) keep shops Mort used to automate. Chests: egg (2 eggs, 3 cards), beer (5 beer, 2 cards), crystal barrel (12 crystals, 4 cards). Duplicates of maxed cards give crystals.
- Sound: a small Web Audio synth in the Sound section (`sfx(name)` plays one of `SOUNDS`: tap, cash, buy, milestone, automate, goal, chest, finale). Notes are steps in the skin's `sound` scale, so each skin has its own voice. Automated shops are silent on purpose. Audio only starts after the first tap or key (browser rule); mute pref key `...-sound`, an on/off switch (`#soundBtn`, `role=switch`) above the volume sliders in the side panel. Ambience: each skin's `sound.ambience` names a recipe in `AMBIENCES` (Ambience section), a steady bed of hums and filtered noise plus random events on timers, built with the small kit in `ambienceKit()`; it fades in, restarts on a skin change, and stops while muted, at zero volume or while the tab is hidden. Effects and ambience have their own buses and sliders in the side panel (pref key `...-volume`, `{fx, amb}` 0-100, defaults 100 and 50, gain is the square). The pane can't be heard, so check a loop by connecting an AnalyserNode to `__game.amb.out` and measuring RMS (the five sit around 0.02).
- Art: the Art section's `ART[skinId]` holds hand-drawn inline SVG: `cards` (a 64x64 portrait per card id, replacing the emoji; cards not found yet show it as a dark silhouette) and `scenes` (a 480x180 banner per episode, shown at the top of that episode's intro and finale). `shops` holds a 48x48 icon per shop, one row of six per episode, drawn on a transparent background over the shop's colored tile (bolder outlines, 2px, because they show at about 52px). `render()` only rewrites an icon button when its skin, episode or shop changes (`r.iconKey`); rewriting a button every frame would drop taps. Skins without art keep emoji. Style: flat shapes, a dark outline (`O`), the skin's palette, a halo circle behind each portrait. Ids inside SVGs must be unique on the page (prefix `art-<skin>-...`). The mall (Grizzle in every scene), Starport Nine (Juno), The Salty Gull (Nell) and Neon Night Market (Kix) have all six portraits, all five scenes and all 30 shop icons (2026-09-30). Planet Cog still uses emoji. Chest results show a small portrait next to each card when the skin has art. Scenes are generated by small Python scripts with helpers for the owner and recurring cast (a head at a position and scale); the SVG strings end up in `ART`. Rob approved this style on 2026-09-30 and wants it for every other setting: flat shapes, outline `O` at about 1.4 (thinner on details), the setting's theme colors plus natural character colors, gradients only as soft glows around light sources. Portraits are head and shoulders with big glowing eyes and one signature prop each. Scenes are layered night scenes with that episode's story props, and the setting's owner appears in every scene. Preview scenes large and make sure no character is hidden behind a prop.
- Story: a `<dialog>` shows an intro per episode (once, tracked by `S.storySeen`) and a finale scene when the finale button is pressed.
- Welcome back: `offline()` credits automated earnings; after a break of `WELCOME_AFTER_S` (5 min) or more it opens a popup (`welcomeBack`) with the time away, the earnings, chests ready to open and whether the finale is ready; shorter breaks get a toast. Popups share the story `<dialog>` and queue (`storyQueue`) if one is already open, e.g. an episode intro on load.
- Saves: localStorage key `grizzle-haunted-mall-v1` (game; the name predates skins and stays for old saves), `...-buymode`, `...-view`, `...-skin`, `...-sound` and `...-volume` (UI prefs, kept separate so resets don't wipe them). Offline earnings are credited on load and when a background tab becomes visible.
- URL flags: `?speed=10` runs faster, `?skin=starport` forces a skin, `?debug` exposes `window.__game` (state, skin, `setSkin` and a few functions).

## Balance target

Episode 1 should take about 30 minutes; the simulator (greedy, always-tapping player) currently gives about 26 minutes, with the fifth goal clearing about 4 minutes before the dragon lease. Later episodes deliberately get longer (Rob chose a long tail): engaged players take about 27, 31, 38, 47, 58 minutes, then 1.2, 1.6, 2.0 and 2.4 hours for episodes 2 to 10 (roughly +25% per episode). Real players are slower. If you change costs or goals, rerun the simulator and update the README numbers.

The simulator also plays casual (10 min every 2 h) and idle (3 min, 3x a day) profiles. Early episodes finish on the second session because income grows exponentially and one break's offline earnings cover the rest of an episode; lowering the offline rate barely helps (even 1% still finishes in 2-3 sessions). On 2026-09-29 Rob chose the long tail over a time gate or accepting it: per-episode costs multiply by 2.5, so idle players take 8 hours per episode for episodes 1 to 5, 16 hours for 6 to 8, then 1 day. The finale bonus used to add +50% per episode, which against x2.5 costs made a wall (time doubling each episode past 8, 12 days by episode 12); on 2026-09-29 it became multiplicative (x1.5 per finale), which keeps the tail gentle. Costs still outpace it slightly (2.5 vs 1.5 to 2), which is the intended slow growth.

## Testing notes

- The in-app browser pane can't run page tools on `file://` URLs. Serve the folder instead (`python -m http.server 8770`, then open `http://localhost:8770/index.html?debug`) and stop the server afterwards. The pane caches the page, so after editing add a throwaway query (`&v=2`) when reloading, or you'll test the old code.
- Automated clicks are instant, so they miss bugs that only happen during a held press. `left_click_drag` from a point to 1px away gives a realistic held press.
- Background tabs pause `requestAnimationFrame`, so taps and income look frozen if the preview tab isn't in front. Front the tab or test functions directly through `?debug`. If the pane itself is hidden, frames stay paused even for the front tab; taking a screenshot makes it render.
- A `beforeunload` handler saves state, so injecting a save then navigating gets overwritten. Override `Storage.prototype.setItem` first if you need to test loading a crafted save.

## Working preferences

- Commit locally as work is done, but ask before pushing. Pushing publishes to the public repo and the live Pages site. After a push, Pages takes about a minute; verify with the Pages build status (`gh api repos/rstibal/monster-shop-idle/pages/builds/latest`).
- End commit messages with a `Co-Authored-By: Claude <model> <noreply@anthropic.com>` line naming the model actually running the session (for example `Claude Opus 5.5`).
- The repo lives at `C:\www\monster-shop-idle` on the main computer (outside OneDrive on purpose; don't put `.git` in a synced folder).
- Keep the UI distinctive, not generic (raised buttons, a strong display font per skin, colors from the skin's theme). No all-caps labels. Rob didn't like the original moss and plum palette; Moonlit graveyard (silver and blue) was the mall's look until 2026-09-29, when he switched to Dripping ectoplasm. When he asks for a new look, show several real options side by side (the game in iframes with the theme swapped) and let him mix colors and fonts.
